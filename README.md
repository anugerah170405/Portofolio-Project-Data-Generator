# Project Data Generator

Project Data Generator adalah tools HTML sederhana yang saya buat untuk mempermudah proses pembuatan data statis project portfolio saya.

Karena portfolio saya masih menggunakan static data dan belum menggunakan backend atau CMS, tool ini membantu mempercepat workflow pembuatan object project tanpa harus menulis manual berulang kali.

---

## ✨ Features

- Generate TypeScript object otomatis
- Live preview project
- Markdown editor untuk:
  - Challenge
  - Solution
  - Result
- Dynamic tags
- Dynamic links
- Dynamic authors
- One click copy output
- Dark / Light mode
- Clean minimalist interface
